PROYECTO LANDING DJANGO

Pasos para ejecutar:

1. Descomprime la carpeta LandingDjango.
2. Abre la terminal dentro de la carpeta donde está manage.py.
3. Ejecuta:

   python manage.py runserver

4. Abre en el navegador:

   http://127.0.0.1:8000/

También funciona:

   http://127.0.0.1:8000/home/

Nota:
Si Django no está instalado, ejecuta:

   pip install django
